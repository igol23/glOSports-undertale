# UNDERTALE - GOODLUCKOS / GA36-MB

Bu paket, goodluckOS'un HOME bölümüne kurulmak üzere hazırlanmıştır. Paket, test edilmiş ARMHF Butterscotch çalıştırıcısını ve goodluckOS başlatıcısını içerir. Undertale oyun dosyaları kullanıcı tarafından sağlanmalıdır.

## GEREKSİNİMLER

- GA36-MB v1.2 (Allwinner A23, Mali-400, 512 MB RAM)
- goodluckOS 0.1.0
- Kullanıcının yasal olarak sahip olduğu Undertale v1.08 Windows oyun dosyaları
- microSD kartta goodluckOS HOME bölümü

## KURULUM

1. SD kartı bilgisayara tak.
2. GitHub Releases bölümünden `undertale-goodluckOS-release.zip` dosyasını indir.
3. ZIP içindeki `.local` ve `ports` klasörlerini SD kartın HOME bölümünün kök dizinine çıkart. Klasörleri birleştirme sorusu gelirse birleştirmeye izin ver.
4. Kendi `data.win` dosyanı ve gerekli `.ogg` ses dosyalarını `HOME/ports/undertale/` klasörüne kopyala.
5. Kartı güvenli şekilde çıkarıp GA36'ya tak.
6. Puppy menüsünü aç ve Games kategorisinden Undertale'i başlat.

## DOSYA DÜZENİ

- `.local/share/applications/undertale.puppy` — Puppy uygulama kaydı
- `ports/undertale/butterscotch` — Pakete dahil ARMHF çalıştırıcı
- `ports/undertale/data.win` — Kullanıcının kendi oyun dosyası
- `ports/undertale/*.ogg` — Gerekli oyun ses dosyaları
- `ports/undertale/start-undertale.sh` — Oyunu başlatan script
- `ports/undertale/saves/` — Kayıt dosyaları

## HATA KAYDI

Oyun başlamazsa aşağıdaki log dosyasını bilgisayarda açıp hata kaydıyla birlikte paylaş:

`/home/player/undertale-launcher-debug.log`
